# Data directory

- `verified_627A.csv`: akippa (627A) daily OHLCV through 2026-10-02, cross-checked against Kabutan and Minkabu; 2026-10-02 is also checked against Yahoo Finance Japan.
- `akippa_metadata.json`: listing metadata from JPX.
- `ipo_master.csv`, `ipo_daily.parquet`, `training_samples.parquet`, `quality_report.csv`, `manifest.json`: generated by `scripts/build_history.py`.

Generated files are intentionally not bundled in this source package because the runtime environment used to assemble this artifact has no direct internet access. The included builder is designed to create them from JPX + Yahoo Finance when run in an internet-connected environment.
