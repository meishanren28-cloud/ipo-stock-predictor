V3（免费日线“预测大师”）更新说明

这版以你给的 v2_full 为底稿直接修改，没有改成付费行情方案。

新增：
1. 开盘条件模型
- 历史训练样本新增“下一交易日真实开盘跳空”作为已知条件。
- 预测目标改为：相对开盘价的当日最高/最低/收盘。
- 适合 9:00 实际开盘后重新计算，口径可以用免费日线做严格样本外回测。
- 8:55 气配也能输入，但明确标为“场景”，不冒充历史8:55气配回测。

2. 自动买点/卖点搜索
- 自动扫描买入价 × 卖出价网格。
- 给出买点触达、卖点触达、两价同日出现、日线能够确定顺序成功的下界、顺序未知部分、买后继续下5%的风险代理。
- 自动生成稳健 / 首选 / 激进方案。
- 如果保守期望没有正优势，允许直接显示“今天不强行做”。

3. 日线先后顺序的保守边界
- 不伪造分钟路径。
- 例如买低→卖高：两价同日出现只是上界；只有能从开盘/收盘关系证明卖价在买入之后的案例才计入成功下界。
- 因此页面显示“确定成功下界 ～ 同日出现上界”。

4. 已有底仓的卖高→回补网格
- 单独搜索适合持仓做T的卖出/回补组合。
- 同样显示顺序确定成功下界与同日出现上界。

5. KNN相似度透明化
- 显示近邻数、有效样本数（effective N）、最近标准化距离、强相似案例数，以及高/中/低相似度等级。
- 不再把“总能找出最近邻”伪装成“历史上一定有高度相似案例”。

6. 开盘大师严格样本外回测
- 按年份 walk-forward，测试IPO整只留出。
- 训练数据不进入测试年份。
- 检查开盘条件模型的 P10/P50/P90 覆盖率、触价概率校准。
- 可用闭卷结果校准开盘大师的最终区间与触价概率。

7. 兼容旧V2历史缓存
- 新建历史库时直接生成开盘目标列。
- 如果已有旧 training_samples.parquet + ipo_daily.parquet，网页会自动补出开盘目标列，不需要重新下载行情。

核心文件：
- app.py
- src/features.py
- src/modeling.py
- src/backtesting.py

仍然不需要：
- J-Quants 分钟线付费包
- Alpha Vantage
- LSEG
- 任何付费行情 API
