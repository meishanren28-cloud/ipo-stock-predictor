IPO模型严格样本外回测补丁

只需要更新2个文件：
1) 用本补丁 app.py 覆盖 GitHub 仓库根目录的 app.py
2) 把 src/backtesting.py 上传到 GitHub 仓库的 src 文件夹

Commit 后 Streamlit Community Cloud 通常会自动重新部署。
部署完成后，网页会新增：
“🧪 模型体检：严格样本外回测 / 分位数校准”

用法：
- 先保持原来的历史库（无需重新找数据）
- 选择未来1/3/5个交易日
- 展开“模型体检”
- 点击“运行严格回测”

回测规则：
- 测试年份 Y 只使用 Y 年1月1日以前的数据训练
- 测试IPO整只留出，不允许同一IPO早期数据进入训练集
- 检查 P10/P50/P90 实际覆盖率
- 检查 P10-P90 区间覆盖率
- 检查相似案例触及概率是否校准（例如模型报50%-60%，实际是否也接近50%-60%）
